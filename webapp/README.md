# 考えるノート Web版

生徒が写真を提出してAIの即時フィードバックを見る画面と、招待コードで結び付いた先生が答案を検索・確認し、AIの案を修正・承認して生徒に届ける画面です。数式は `$...$` / `$$...$$` のLaTeXとしてKaTeXで表示します。画像は誤り行をハイライトし、短い見直しの問いを付けてPNGとして保存できます。

## ローカルでの設定

1. Python 3.9以上で `pip install -r webapp/requirements.txt` を実行します。
2. Google Cloudでウェブアプリ用OAuthクライアントIDを作り、Google Identity Servicesの承認済みJavaScript生成元にアクセス先を登録します。`localhost` での検証も実際に利用するポートを登録してください。
3. `GOOGLE_CLIENT_ID` にクライアントID、`TEACHER_EMAILS` に先生のGoogleアカウントのメールアドレス（複数ならカンマ区切り）を設定します。リスト外のアカウントは生徒です。先生はGmailまたはGoogle Workspaceの確認済みアカウントに限ります。
4. Vertex AIを有効化し、Application Default Credentialsと `GOOGLE_CLOUD_PROJECT`、`GOOGLE_CLOUD_LOCATION`、`GEMINI_MODEL` を設定します。利用可能なマルチモーダルGeminiモデルを指定します。認証情報はコミットしません。
5. `python3 webapp/server.py` で起動し、`http://localhost:8080` を開きます。Googleログイン、KaTeX、AI呼び出しにはネットワーク接続が必要です。AIやGoogleログインが未設定のときは擬似結果を返しません。

設定項目のひな形は `.env.example` です。サーバーはファイルを自動で読み込まないため、各値を実行環境の環境変数として設定してください。OAuthクライアントIDは秘密鍵ではありませんが、サービスアカウント鍵やアクセストークンはGitに保存しないでください。

先生が「招待コード」からコードを生徒に個別に渡し、生徒が「先生とつながる」で入力します。その先生だけが生徒の提出を検索・閲覧できます。生徒は自分の答案・即時フィードバック・送信済みの先生のフィードバックだけを見られます。先生の下書きと対話は承認前に生徒には公開されません。Classroom API接続は不要で、ClassroomにはサイトURLをリンクとして掲載できます。招待コードは公開せず個別に共有してください。

## 運用上の制約

現在はSQLiteを使う単一サーバーの試作です。データは `webapp/coach.sqlite3` に保存されます（`COACH_DB_PATH` で変更可能）。端末間共有には全員が同じサーバーに接続する必要があります。標準設定は `127.0.0.1` のみで待ち受けます。公開にはHTTPS、アクセス制限、永続ディスク、バックアップ、画像の保存期限・削除、運用監視が必要です。Cloud Runのコンテナローカルディスクは永続ではなく、複数インスタンスでSQLiteを共有できないため、このままCloud Runにデプロイしないでください。

本人確認・権限分離を実装していますが、実際のGoogleアカウント、実画像、AI応答を使った検証やセキュリティ監査は未実施です。実際の生徒の個人情報を含む答案には使用しないでください。AIは誤読や不適切なヒントを返す可能性があり、先生による確認が必要です。

テスト: `python3 -m unittest discover -s webapp -p 'test_*.py' -v`
